# kaimera.dev

Source for [kaimera.dev](https://kaimera.dev) — Astro + React + Tailwind, with interactive demos (deck.gl / MapLibre).

```sh
npm install
npm run dev      # regenerates demo data, then starts the dev server
npm run build    # static build to dist/
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
